# 📸 Фотобатл-бот для Telegram

## Що вміє
- **/start** — привітання, тема, приз, дедлайни + кнопки «Взяти участь», «Правила», «Приз», «Моя заявка»
- Учасник кидає фото в ЛС → бачить превʼю → «✅ Надіслати» (одне фото на людину, до модерації можна замінити)
- Адміни отримують фото з кнопками **Прийняти / Відхилити**
- Прийняте фото публікується в канал під номером з кнопкою **❤️ N**
- Голос: один на людину за кожне фото, повторне натискання знімає голос, за себе не можна, опційно — тільки підписники каналу
- Учасник отримує сповіщення про статус і посилання на свій пост

## Адмін-команди (в ЛС боту)
| Команда | Що робить |
|---|---|
| `/admin` | список команд |
| `/stats` | статистика |
| `/top 10` | топ за голосами |
| `/close_photos` / `/open_photos` | закрити / відкрити прийом фото |
| `/close_voting` / `/open_voting` | зупинити / відновити голосування |
| `/remove 3` | дискваліфікувати учасника №3 (пост видаляється) |
| `/finish` | закрити все, опублікувати 🥇🥈🥉 у каналі, написати переможцю |
| `/broadcast текст` | розсилка всім, хто надсилав фото |

## Запуск
1. Створи бота в **@BotFather**, скопіюй токен
2. Створи канал, додай бота **адміном** (право публікувати й редагувати повідомлення)
3. Свій ID дізнайся в **@userinfobot**
4. ```bash
   npm install
   cp .env.example .env   # заповни токен, ID, канал, приз, дати
   npm start
   ```

Дані зберігаються в `data.json` поруч із ботом — не видаляй його під час конкурсу.
Для хостингу 24/7 підійде будь-який VPS (`pm2 start bot.js --name photobattle`) або Railway/Render.
